Data & ChatGPT

Move data between devices

Export creates one backup containing every profile. Import restores a multi-profile backup or an older single-profile backup.

Copy Latest Summary uses the currently selected profile. On phones, Share Latest opens the normal share sheet when supported.

Phone use

Open the hosted HTTPS site in Safari/Chrome. On iPhone you can use Share → Add to Home Screen so it behaves more like an app. Data is still cached locally even when GitHub sync is enabled.
